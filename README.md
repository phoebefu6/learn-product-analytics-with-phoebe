# Product Analytics: Events to Decisions

Fourteen 45-minute sessions on product analytics from the event up, by Phoebe Fu.

- **Leader track (6, no code):** the tracking plan, activation and aha moments, engagement you can defend, feature adoption, measuring an AI feature, the product review.
- **Analyst track (8, Python and the browser):** real public GitHub activity from [GH Archive](https://www.gharchive.org/), from one raw hour to a bench that tests activation definitions on 8,348 real repositories born in one hour, computed live in the page.

Every number on the bench is a count from real rows, reproduced by an independent Python reference. The code-assistant event stream used in the AI sessions is constructed from a fixed seed and labelled as such wherever it appears.

Open `index.html` to start. Build scripts for every number live in `materials/`.
